# Tower Pedestal Kit for Unity

This kit creates 4 stylized tower pedestal prefabs inspired by the provided concept:
- Pedestal_Desert
- Pedestal_Snow
- Pedestal_Summer
- Pedestal_Autumn

## Install
1. Unzip this package.
2. Copy the folder `Assets/TowerPedestalKit` into your Unity project's `Assets` folder.
3. Unity will compile the script and automatically generate materials and prefabs.
4. Find the prefabs in `Assets/TowerPedestalKit/Prefabs`.

## Notes
- Designed as a clean stylized approximation of the reference pedestal.
- Footprint is 10 x 10 Unity units to match a 10-unit tile grid.
- Prefabs are generated as 3 stacked layers.
- Materials use URP Lit if available, then Standard, then Unlit/Color fallback.
