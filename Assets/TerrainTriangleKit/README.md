Terrain Triangle Kit Addon for Unity

This addon contains triangle-cut versions of the 96 tiles from the original TerrainTileKit.
Each source tile has 4 triangle orientations:
- SW = right angle at south-west corner
- SE = right angle at south-east corner
- NW = right angle at north-west corner
- NE = right angle at north-east corner

Import into the same Unity project as the original kit or by itself.
Then use Tools -> Terrain Triangle Kit -> 1. Generate Materials and Prefabs
Optionally use 2. Create Demo Scene.
All tiles are designed around the same 10x10 unit grid and Y=0 placement.
